# Artify JS Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and verify a publishable, local-only browser image stylization library with sixteen distinct presets, composable pipelines, a Worker path, and a Vite playground.

**Architecture:** DOM image decoding and canvas encoding live at the browser boundary while all artistic processing operates on a testable `Frame` typed-array abstraction. Presets compose registered filters and effects through a seeded pipeline; a transfer-based Worker runs the same frame renderer without duplicating algorithms.

**Tech Stack:** TypeScript, Vite, Vitest, pnpm, ESLint flat config, Prettier, Canvas 2D, Web Workers.

**Spec:** `docs/superpowers/specs/2026-10-12-artify-js-design.md`

## Global Constraints

- The public npm package name is `@typeofnan/artify-js` and the license is MIT.
- The primary runtime is modern evergreen browsers; core `ImageData`-shaped transforms remain DOM-independent.
- Core image processing has no runtime dependencies and performs no network requests.
- The v1 renderer is Canvas 2D plus typed-array algorithms; WebGL/WebGPU and AI are out of scope.
- All stochastic effects must be byte-deterministic when given the same input, options, and seed.
- Production behavior is implemented test-first and verified with lint, typecheck, tests, build, and formatting checks.

## Review Focus

- Transparent input: style output must preserve source alpha unless the selected border effect intentionally reduces it; Task 2 tests this.
- Tiny and zero-sized input: 1x1 frames must render safely and zero dimensions must throw `INVALID_DIMENSIONS`; Task 1 tests both.
- Invalid numeric options: NaN and infinities must not enter loops or buffers; Task 3 tests normalization and rejection.
- Cancellation during CPU work: abort must reject with `ABORTED` between stages and in long transforms; Task 4 tests it.
- Cross-origin/failed URL decode and unsupported export MIME: browser boundaries must return typed errors, not hang or mislabel output; Task 5 tests both.
